## Problems and traps
- NaN bits: x86_64 and aarch64 produce different default NaNs and Rust leaves NaN sign and
  payload unspecified, so "bit-identical" in the spec excludes NaN results everywhere except
  `det`, which returns `0x7FC0_0000`.
- SSE `minps` and NEON `vminq_f32` disagree with each other and with `f32::min` on NaN and signed
  zero; the spec defines `min`/`max` by one comparison so any path can match it.
- CODE_STYLE.md's ban list does not cover `asin`, `acos`, `atan`, `atan2`, `powi`, `hypot`,
  `mul_add` and others (spec §12 item 10). MATH-R004 bans them for this crate only.
- An orthographic matrix with bounds near ±100 and a width of 0.1 loses about 2e-4 to
  cancellation; MATH-R051's property domain is narrower for that reason.
- `docs/specs/README.md` and `docs/STATUS.md` will conflict with other spec branches.
