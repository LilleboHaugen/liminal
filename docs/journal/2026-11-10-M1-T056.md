## Decisions
- XTASK-R014 tests one package per command instead of `--workspace --no-default-features`:
  Cargo unifies features over the packages of one command, so a member that enables
  `telemetry` (for example `liminal_benches`) would switch the `cfg(not(feature))` tests off
  again without any failure.
- A repository without any package with features passes the step without running a test
  command. That is the state today; the step first does real work when M1-T028 adds
  `liminal_telemetry`.
- ADR-0018's benchmark clause is stated not to apply to the ring buffer (task item 3, first
  option); the reference stays private. No ADR: the spec applies ADR-0016 and ADR-0018, it
  changes neither. The reviewer may see it differently (task "Handoff", "For the reviewer" 1).
- Gauge `min` and `max` in the summary are over finite values only (TELE-R093).
