## Decisions
- Harness errors implement `liminal_core::error::EngineError` (ADR-0017), so `liminal_core` is a
  normal dependency of `liminal_benches` (allowed: lower layer).
- Measurement logic takes an internal `Clock` trait so warm-up, calibration and sampling are
  tested with a clock the routine advances (TESTING.md: no wall-clock assertions).
- New `check-arch` requirement numbered XTASK-R090 (the R030–R039 group is full); the group
  heading now reads R030–R039, R090–R099. M1-T017 should number its `bench` requirements
  elsewhere (for example R100 onward).
- Scope addition in M1-T016 (written in its handoff): the coverage file filter. Without it,
  cargo-llvm-cov 0.9.1 skips everything under `<workspace>/benches/` and the crate's floor would
  be meaningless.

  workspace root, so a crate at `benches/` measures "no lines measured". Fixed by xtask's own
  filter (XTASK-R060 details).
- `cargo test` does not build bench targets; only `clippy --all-targets` compiles them.
- `power` was `battery` during the run: baselines (M1-T017) need the machine plugged in.
