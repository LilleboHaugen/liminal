## Decisions
- The integer inverse property compares by value, not bits: an integer zero cofactor carries
  no sign, the `f32` evaluation gives `-0.0` or `0.0` depending on the expression. Bits of the
  inverse are still fixed by MATH-R045's expression; the value comparison is enough to catch any
  wrong adjugate term.

## Problems and traps
- `determinant_is_exact_for_small_integers` was flaky at a low rate (determinant above
  `i16::MAX`, about 1 run in several hundred). Once proptest has saved a failing seed, every later
  run replays it, so a stress loop counts every run after the first failure as failed.
- A proptest strategy that rejects most inputs aborts after 1024 global rejects; generate
  inside the domain (`prop_flat_map`) instead.
