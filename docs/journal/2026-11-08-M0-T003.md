## Problems and traps
- A blank line ends a Markdown table. Index rows after it are not part of the index.
- Mutation testing leaves `xtask/proptest-regressions/` behind. Delete it unless it records a
  real bug.
- Mutation testing with `cp f f.orig; <mutate>; mv f.orig f` leaves a stale build. The restored
  file keeps the older `cp` mtime, so cargo keeps the last mutant's binary. Symptom: `ci` failed
  `repo::tests::loads_the_real_repository` (the last mutant had removed the `target` exclusion)
  until `repo.rs` was touched. Run `touch f` after restoring, or use `cp -p`. Results of the
  mutants themselves are valid: each one changes a file and forces a rebuild.
