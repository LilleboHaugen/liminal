## Done
- `docs/specs/liminal_math.md`, `spec_version` 1 → 2. Each change and its reason:
  - **MATH-R023.** "For all finite inputs `a.cross(b) == -(b.cross(a))`" was false: with
    `a = b = (0, 3e19, 3e19)` both products overflow and `x` is `∞ − ∞ = NaN` on both sides.
    Now: for every bit pattern, each component pair is both NaN or equal under `==`. The domain
    was widened instead of narrowed because the statement is then true everywhere (the two
    sides subtract the same two products in opposite order). "Same bits" would be false:
    `p − p = +0`, `−(p − p) = −0`.
  - **MATH-R160, MATH-R165, MATH-R175, §7 (INV-3 to INV-5).** Option (a) of the task: the four
    geometry constructors reject a vector to normalize whose `length_squared()` is below
    `f32::MIN_POSITIVE`. Reason for (a): `normalize` and the exact expressions of MATH-R022 and
    MATH-R024 stay as they are (option (b) changes them for every caller), and the invariants
    stay unconditional (option (c) lets non-unit normals exist). The rejected inputs are
    vectors shorter than 1.1e-19.
  - **New error code LIM-MATH-0015 `VectorTooShort { parameter, length_squared }`** (§5.8, §8),
    for `Plane::from_normal_and_point` and `Ray::new`. LIM-MATH-0001 was not reused: its
    message says "length zero". `Plane::from_points` reports LIM-MATH-0013 and the frustum
    LIM-MATH-0014 for the same condition; both messages and the 0013 help were widened.
  - **MATH-R175 also rejects a non-finite plane `d`.** `e ÷ l` can overflow for a finite
    matrix; INV-3 requires a finite `d`. Not in the task's list, but acceptance criterion 2
    needs it.
  - **MATH-R004.** Adds conversion `f32 → f64` (exact) and `f64 → f32` (round to nearest, ties
    to even), which a `det` function evaluated in `f64` needs; also states how integer and
    float conversions round and names `from_bits`.
  - **MATH-R072.** `Quat::IDENTITY * v == v` holds for finite `v` only (`0 × ∞ = NaN`).
  - **§4 "Stable case".** One shape per case is varied: the receiver sphere for MATH-R157, the
    shape the ray is tested against for MATH-R169.
  - §10: rows for the new unit cases and a property test of INV-3 to INV-5; §12 item 1; §14.
- `docs/tasks/M1-T060-liminal-math-spec-follow-ups.md`: status, criteria, handoff.
