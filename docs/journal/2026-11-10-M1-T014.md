## Decisions
- Oracles (spec §10, `spec_version` 4). The session was not permitted to compile and run
  downloaded code, so the reference C files were not run. XXH64 is checked against the
  published xxHash sanity vectors; xoshiro256\*\* and SplitMix64 against the outputs published
  in the `rand_xoshiro` tests; everything derived (seeding, bounded integers, floats, encoding
  literals) against `kat.py`, written from the algorithm descriptions with unbounded integers.
- `DetHashMap` / `DetHashSet`: `Debug` is hand-written (`{k: v}` / `{v}` in iteration order)
  instead of derived, so assertion messages do not print the index table. Same bounds as the
  derive. Spec §5.4 changed with it.
- `DetHashMap` layout: `Vec` of entries (hash, key, value) in insertion order plus a table of
  entry positions (linear probing, load factor at most 1/2, no tombstones). `remove` shifts the
  entries and rebuilds the table. No `unsafe`, no dependency.
- CORE-R114 now states `Tick::default()` and `TickDuration::default()` (backlog entry of the
  M1-T055 review).
- The task branch was pushed before the handoff commit to run the three-platform CI that the
  §11 statement and the determinism gate need.
